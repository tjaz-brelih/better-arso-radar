# Better Radar

Better Radar is loosely based on ARSO INCA application.
The main goal of this app is to provide a more user-friendly experience of showing precipitation radar images generated by ARSO (Slovenian environmental agency).

Live page can be accessed [here](https://tjaz-brelih.github.io/better-arso-radar).

## Features

- Auto-refresh: Radar images are automatically refreshed every 5 minutes. Manual refresh is also available.
- Custom markers: Custom markers can be placed on the map by using mouse right-click. Remove them by double-clicking.
- Scrubbing through images: Scrub through radar images by using the integrated slider.


## Technologia

This project is built using [Angular](https://angular.dev) v22, [TailwindCSS](https://tailwindcss.com/) v4.3 and [Leaflet](https://leafletjs.com) v2-alpha.
Map tiles are provided by [OpenStreetMap](https://www.openstreetmap.org).
Radar images are provided by [ARSO](https://www.meteo.si).

### Run the app localy

To run this app localy a installation of Node.js is required.
Check [here](https://angular.dev/reference/versions) to see which version of Node.js is required depending on the currently used version of Angular.
The currently used version of Angular can be checked in the `package.json` file within this repository.

To start a local development server, run:

```bash
npm run start
```

Once the server is running, open your browser and navigate to `http://localhost:17433/`. The application will automatically reload whenever you modify any of the source files.
